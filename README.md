## 로컬에서 미리보기

```bash
# Python (간단)
python -m http.server 8000

# 또는 Node
npx serve .
```

브라우저에서 http://localhost:8000 접속.

## GitHub Pages 활성화

1. GitHub에 이 폴더를 새 저장소(`spoonful-privacy`)로 push
2. Settings → Pages
3. Source: `Deploy from a branch`
4. Branch: `main` / Folder: `/ (root)` 선택
5. Save → 1~2분 대기 → 활성화 완료
6. URL: `https://<username>.github.io/spoonful-privacy/`

## 업데이트 방법

내용 변경 시:
1. HTML 파일 직접 수정

3. 자동으로 GitHub Pages 재배포 (1~2분)
